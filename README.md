A simple project that demonstrates the implementation of a Tree Data Structure using Object-Oriented Programming (OOP) in Java.

It uses an array-based representation of a Complete Binary Tree and includes the following operations:

- Insertion: Adds elements to the tree.
- Searching: Finds a specific value in the tree.
- In-Order Traversal: Displays the tree elements in left-root-right order.

The program allows users to enter the number of elements, input their values, display the in-order traversal, and search for a specific value.

Concepts Used:
- Object-Oriented Programming (OOP)
- Abstract Classes
- Inheritance
- Arrays
- Recursion
- Tree Data Structures

Lnaguage: Java
